# Glasscliff.com

The independent guide to high-stakes leadership roles: for people weighing a "glass cliff" role, and for the boards that appoint them.

- **Traffic engine:** 10 original guides, a Research Library, glossary, video library and daily leadership news (monetised with Google AdSense).
- **Money engine:** a dedicated lead-generation section, the [Confidential Review](get-help.html), plus Board Appointment Reviews and a paid Advisor Network.
- **Interactive tools:** Risk Scanner, Offer Protection Builder, 100-Day Planner, Readiness Check, Board Appointment Check.
- **Other revenue and community:** support/donations, the Edge Prize (quarterly contests with prizes), careers/talent pool, advertising and sponsorship packages, Pulse Survey.

Live preview (GitHub Pages): `https://webworksa1.github.io/glasscliff-com/`

## How it is built

Pages are generated by one Python script with no dependencies, then stored in Jekyll layout format: every page holds its own head tags, schema and content, and `_layouts/default.html` supplies the shared owner bar, header, footer, AdSense tag and scripts. GitHub Pages renders this natively from `main` / root on the free plan.

To rebuild after editing anything in `_build/`: `python3 _build/build.py && python3 _build/jekyll_export.py`. (`build.py` alone writes plain full-HTML pages, which also work on any static host.)

| Path | What it is |
|---|---|
| `_build/build.py` | Builds every page. Run `python3 _build/build.py` after editing anything in `_build/`. `--news` also refreshes headlines. |
| `_build/common.py` | Shared layout: owner bar, header, footer, AdSense tag, SEO tags, form helpers |
| `_build/guides_a.py`, `guides_b.py` | The ten guides (content, FAQs, sources) |
| `_build/refdata.py` | Research studies, timeline, glossary, videos, FAQ, jobs, ad packages, news queries |
| `_build/pages_*.py` | Page templates (content, tools, lead generation and monetisation pages) |
| `_build/jekyll_export.py` | Converts the built pages to the shared-layout Jekyll format (`--check` proves the output is identical) |
| `_layouts/default.html` | Shared chrome for every page (owner bar, header, footer, AdSense, scripts) |
| `assets/js/config.js` | **Edit me:** payment links, prizes, advisor plan prices, form relay key |
| `assets/js/main.js`, `tools.js` | Forms, lead scoring, self-updating widgets, search · the five tools |
| `data/news.json` | Daily headlines (written by the automation) |
| `automation/site.yml` | Daily news refresh, rebuild and social-image workflow, ready to activate (see below) |
| `BUILD-PROMPT.md`, `RESEARCH.md` | Phase-wise build prompt · research on 39 comparable sites (not published) |

## Publish on GitHub Pages (one-time)

Settings → Pages → Build and deployment → Source **Deploy from a branch** → Branch **main**, folder **/ (root)** → Save. The site is live at the preview URL within a few minutes.

1. DNS at the registrar: A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; CNAME `www` → `webworksa1.github.io`.

3. Canonical URLs, the sitemap and `robots.txt` already point at `https://glasscliff.com`.

## Forms (confidential review, organisations, advisers, support pledges, prize entries, careers, advertising, survey, contact, newsletter)

All forms post through FormSubmit's AJAX endpoint to the single owner inbox. The address is stored only as an encoded relay key in `assets/js/config.js`, is assembled in the browser at the moment of sending, and never appears in page source, page text, data files or this repository. The "Write to us" link on the contact page builds its email link only when clicked.

- **The first submission triggers a one-time FormSubmit activation email. Click Activate**, or later submissions will not be delivered.
- After activation, FormSubmit shows a random alias. Paste it into `formAlias` in `config.js` to stop using the encoded address entirely.
- Review and organisation leads arrive with a 0–100 lead score, tool score, first landing page, referrer and UTM tags.

## Donations

Paste PayPal.me, Stripe Payment Link, Buy Me a Coffee or Ko-fi URLs into `assets/js/config.js` → `payments`. Until then the Support page runs in pledge mode: the pledge arrives by email and you reply with a payment link.

## AdSense

- The tag for `ca-pub-6620975821265271` is in the `<head>` of every content page, with the `google-adsense-account` meta tag. It is left off `thank-you.html` and `404.html` because they carry no publisher content.
- `ads.txt` is at the root. Apply once `https://glasscliff.com/ads.txt` resolves on the custom domain.
- After approval: turn on Auto ads, and enable the Google-certified consent message for EEA/UK/CH under Privacy & messaging. If auto ads appear inside the lead form on `get-help.html`, exclude that page under Auto ads → Page exclusions.

## Daily automation (one-time activation)

GitHub does not let integrations create workflow files, so the workflow ships in `automation/site.yml`. To switch it on: open `automation/site.yml` on GitHub, copy its contents, then **Add file → Create new file**, name it `.github/workflows/site.yml`, paste and commit. From then on it:

- runs every day at 05:17 UTC (and on demand from the Actions tab), refreshing `data/news.json` from Google News (headlines and links only);
- rebuilds every page and the sitemap whenever `_build/` changes;
- renders `assets/img/og.png` (social share image) and `assets/img/icon-512.png` from their SVG sources;
- commits only when something changed and requests a Pages build.

Without it the site still works: the "Edge note of the day", contest countdowns, quarter labels and copyright year update themselves in the browser, and the news list shows the last saved headlines.
